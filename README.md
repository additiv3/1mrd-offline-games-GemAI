## 🚀 App starten

**▶ [https://additiv3.github.io/1mrd-offline-games-GemAI/](https://additiv3.github.io/1mrd-offline-games-GemAI/)**

### Auf dem iPhone installieren
1. Link in **Safari** öffnen
2. Unten auf **Teilen** → **Zum Home-Bildschirm** tippen
3. App erscheint wie eine normale App auf dem Home-Screen

### Auf Android installieren
1. Link in **Chrome** öffnen
2. Menü **⋮** → **App installieren**

### Auf dem Laptop / Desktop
- Einfach im Browser öffnen – funktioniert sofort
- Optional: In Chrome oben rechts auf **⊕ Installieren** klicken

## ✨ Features

- 📴 **100 % offline** – kein Internet nötig
- 📱 **iPhone & Android** – als PWA installierbar
- 💻 **Laptop/Desktop** – Maus + Tastatur voll unterstützt
- 🎁 **Täglicher Bonus** – Glücksrad jeden Tag drehen
- 🏆 **Herausforderungen** – Ziele erfüllen, Münzen sammeln
- 🛍️ **Shop** – Münzen gegen Skins & Extras tauschen
- 🕐 **Version + Uhrzeit** direkt auf der Startseite sichtbar
- 💾 Spielstände werden lokal gespeichert (nur auf deinem Gerät)
